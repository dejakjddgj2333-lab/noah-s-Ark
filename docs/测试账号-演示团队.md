## 观察点

1. **结算/佣金**：成员买的是"新手体验 7天"（每日结算），每满 24 小时结算一期；demo_root 收益账户可看到三级佣金流水（含代数、比例、结算时团队等级），demo_a1 只能看到一代佣金（0级仅一代）。
2. **团队页**：demo_root 显示 2 级比例 5%/3%/2%；demo_a1 显示 0 级仅一代 5%。
3. **VIP 页**：demo_root 显示 VIP5（9%），持仓进度 20,000/40,000 指向 VIP6。
4. **到期降级**：7 天到期后成员持仓归零，demo_root 团队等级会实时跌落，等级变动日志会逐级留痕。
5. **邀请页**：任一账号可复制自己的邀请码/链接发展新下级（注意：已有购买记录的账号补绑/绑定规则受全层级购买检查约束）。
