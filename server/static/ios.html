INSTALL STEPS · 四步完成安装
1

下载描述文件

用 Safari 打开本页,点上方「下载安装APP」。弹出「此网站正尝试下载一个配置描述文件」时,点「允许」。

2

打开设置,找到描述文件

回到桌面打开「设置」,首页顶部会出现「已下载描述文件」,点它进入。(也可走 设置 → 通用 → VPN与设备管理)

3

安装「明策」描述文件

点右上角「安装」,输入锁屏密码,再点一次「安装」确认。看到红色的「未签名」提示属正常现象,继续安装即可(下方有说明)。

4

完成,从主屏幕进入

回到主屏幕,出现「明策」图标即安装成功。以后点图标全屏打开终端,不用再走浏览器。

关于安装时的「未签名」红色提示

该提示仅表示描述文件未附加苹果开发者签名认证,不影响安装与使用。本描述文件由明策官方邀请页直发,内容仅为「主屏幕图标 + 接入证书」两项,不含任何监控或 VPN 配置,可随时在 设置 → 通用 → VPN与设备管理 中查看与移除。

FAQ · 常见问题
不想装描述文件,有别的方式吗?
有。用 Safari 打开 m.mingcevip.com,点底部分享按钮 「添加到主屏幕」即可,效果相同。描述文件方式的优势是图标与全屏体验更稳定。
安装时需要输入描述文件密码吗?
不需要。接入证书密码已内置在描述文件中,全程只需输入一次你手机的锁屏密码。
以后想卸载怎么办?
打开 设置 → 通用 → VPN与设备管理 → 点「明策」→「移除描述文件」即可,主屏幕图标会一并消失,不影响已注册的账号数据。
装好后和网页版是同一个账号吗?
是。图标打开的就是明策移动端网页版,行情、聊天、资产数据与 PC 端、安卓端实时同步。
